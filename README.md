# Writeups

Coleção de writeups de desafios de CTF (Capture The Flag) que resolvi, cobrindo
categorias como **reversing**, **pwn**, **web**.

Cada writeup documenta o processo de resolução: reconhecimento, análise,
ferramentas utilizadas, raciocínio passo a passo e a solução final.

## Aviso

Todos os writeups aqui são de desafios **autorizados** (CTFs, labs próprios,
plataformas de treinamento).
O conteúdo é **exclusivamente educacional**. Não use as técnicas descritas
contra sistemas sem autorização explícita por escrito — isso é crime.
